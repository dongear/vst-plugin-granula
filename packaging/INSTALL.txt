GRANULA — installation / установка
==================================

Two plugins are included / В архиве два плагина:
  Granula     — instrument: drop a sample in, play it with MIDI
                инструмент: закиньте сэмпл и играйте по MIDI
  Granula FX  — effect: granulates the audio on a track
                эффект: гранулирует звук на дорожке

macOS
  Easiest: double-click "install-mac.command".
  If macOS says it can't be opened: right-click it -> Open -> Open.

  Проще всего: дважды кликните "install-mac.command".
  Если macOS не даёт открыть: правый клик -> Открыть -> Открыть.

  Manual / вручную:
    *.vst3      -> ~/Library/Audio/Plug-Ins/VST3/
    *.component -> ~/Library/Audio/Plug-Ins/Components/
    then in Terminal / затем в Терминале:
    xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/Granula*.vst3 ~/Library/Audio/Plug-Ins/Components/Granula*.component

WINDOWS
  Copy "Granula.vst3" and "Granula FX.vst3" to:
      C:\Program Files\Common Files\VST3\
  Then rescan plugins in your DAW.
  Скопируйте оба .vst3 в эту папку и пересканируйте плагины в DAW.

LINUX
  Copy both .vst3 to ~/.vst3/

USING THE INSTRUMENT (Ableton etc.) / КАК ИГРАТЬ
  1. Put "Granula" on a MIDI track.
  2. Drag an audio file (wav/aiff/flac/mp3/ogg) onto the plugin window,
     or click "LOAD SAMPLE".
  3. Play notes. C3 = original pitch. Scan moves through the sample.

  1. Поставьте "Granula" на MIDI-дорожку.
  2. Перетащите аудиофайл в окно плагина или нажмите "LOAD SAMPLE".
  3. Играйте нотами. C3 = исходная высота. Scan — движение по сэмплу.

PRESETS / ПРЕСЕТЫ
  SAVE button saves your own preset. Presets live in:
    Documents/Granula Presets/
  Share a .granula file with a friend: they drag it onto the plugin.

  Кнопка SAVE сохраняет ваш пресет (папка Документы/Granula Presets).
  Пресетом можно поделиться: другу достаточно перетащить файл .granula на плагин.
