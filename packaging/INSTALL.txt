GRANULA — installation / установка
==================================

WINDOWS
  Copy "Granula.vst3" to:
      C:\Program Files\Common Files\VST3\
  Then rescan plugins in your DAW.
  Granula.exe is a standalone version (no DAW needed).
  If Windows SmartScreen warns you: "More info" -> "Run anyway".

  Скопируйте "Granula.vst3" в  C:\Program Files\Common Files\VST3\
  и пересканируйте плагины в DAW. Если SmartScreen ругается:
  "Подробнее" -> "Выполнить в любом случае".

macOS
  VST3:  copy "Granula.vst3"      to  ~/Library/Audio/Plug-Ins/VST3/
  AU:    copy "Granula.component" to  ~/Library/Audio/Plug-Ins/Components/
  The plugin is not notarized by Apple yet, so macOS may block it.
  Fix it once in Terminal:
      xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/Granula.vst3
      xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/Components/Granula.component
  (For Logic / GarageBand use the AU version.)

  Плагин пока не нотаризован Apple, поэтому macOS может его заблокировать.
  Один раз выполните команды выше в Терминале.

LINUX
  Copy "Granula.vst3" to ~/.vst3/
