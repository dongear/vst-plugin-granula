ARTEMPIDOR + INTERFERENCE — installation / установка
====================================================

This archive has two plugins / в архиве два плагина:
  artempidor    — granular instrument / гранулятор (MIDI track)
  Interference  — harmonic sweetener effect / эффект: подтягивает звук в тональность

macOS
  Easiest: double-click "install-mac.command".
  If macOS says it can't be opened: right-click it -> Open -> Open.

  Проще всего: дважды кликните "install-mac.command".
  Если macOS не даёт открыть: правый клик -> Открыть -> Открыть.

  Manual / вручную:
    *.vst3      -> ~/Library/Audio/Plug-Ins/VST3/
    *.component -> ~/Library/Audio/Plug-Ins/Components/
    then in Terminal / затем в Терминале:
    xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/artempidor.vst3 ~/Library/Audio/Plug-Ins/VST3/Interference.vst3 ~/Library/Audio/Plug-Ins/Components/artempidor.component ~/Library/Audio/Plug-Ins/Components/Interference.component

WINDOWS
  Copy "artempidor.vst3" and "Interference.vst3" to  C:\Program Files\Common Files\VST3\
  and rescan plugins in your DAW.
  Скопируйте оба .vst3 в эту папку и пересканируйте плагины.

LINUX
  Copy both .vst3 to ~/.vst3/

HOW TO USE / КАК ПОЛЬЗОВАТЬСЯ
  artempidor is an instrument: put it on a MIDI track.
  artempidor — инструмент: ставьте его на MIDI-дорожку.

  SAMPLE mode / режим SAMPLE
    Drag an audio file (wav/aiff/flac/mp3/ogg) onto the plugin window
    (or click LOAD SAMPLE) and play notes. C3 = original pitch.
    Перетащите аудиофайл в окно плагина и играйте нотами. C3 = исходная высота.

  INPUT mode / режим INPUT  (granulate another track live)
    Ableton: in the plugin's device header open "Sidechain" (triangle icon),
    enable it and choose the source track in "Audio From".
    Logic: "Side Chain" menu at the top of the plugin window.
    Ableton: в заголовке плагина откройте "Sidechain", включите его и
    выберите дорожку-источник в "Audio From".

PRESETS / ПРЕСЕТЫ
  SAVE saves your own preset to Documents/artempidor/Presets.
  Share a .artempidor file: the other person drags it onto the plugin.
  SAVE сохраняет ваш пресет. Чтобы поделиться — перетащите файл
  .artempidor на окно плагина.

INTERFERENCE (effect / эффект)
  Put it on any audio track. Pick the key (or click notes on the keyboard),
  turn COLOR. Above 100% in-key notes ring into a tail.
  HQ mode is more precise and enables SNAP (moves off-key notes into key).
  MIDI KEY: send MIDI to the plugin and the key follows the chord you play.
  Ставьте на любую аудиодорожку, выберите тональность (или кликайте ноты),
  крутите COLOR. HQ точнее и включает SNAP. MIDI KEY — тональность по аккорду.
