ARTEMPIDOR — installation / установка
=====================================

macOS
  Easiest: double-click "install-mac.command".
  If macOS says it can't be opened: right-click it -> Open -> Open.

  Проще всего: дважды кликните "install-mac.command".
  Если macOS не даёт открыть: правый клик -> Открыть -> Открыть.

  Manual / вручную:
    artempidor.vst3      -> ~/Library/Audio/Plug-Ins/VST3/
    artempidor.component -> ~/Library/Audio/Plug-Ins/Components/
    then in Terminal / затем в Терминале:
    xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/artempidor.vst3 ~/Library/Audio/Plug-Ins/Components/artempidor.component

WINDOWS
  Copy "artempidor.vst3" to  C:\Program Files\Common Files\VST3\
  and rescan plugins in your DAW.
  Скопируйте "artempidor.vst3" в эту папку и пересканируйте плагины.

LINUX
  Copy artempidor.vst3 to ~/.vst3/

HOW TO USE / КАК ПОЛЬЗОВАТЬСЯ
  artempidor is an instrument: put it on a MIDI track.
  artempidor — инструмент: ставьте его на MIDI-дорожку.

  SAMPLE mode / режим SAMPLE
    Drag an audio file (wav/aiff/flac/mp3/ogg) onto the plugin window
    (or click LOAD SAMPLE) and play notes. C3 = original pitch.
    Перетащите аудиофайл в окно плагина и играйте нотами. C3 = исходная высота.

  INPUT mode / режим INPUT  (granulate another track live)
    Ableton: in the plugin's device header open "Sidechain" (triangle icon),
    enable it and choose the source track in "Audio From".
    Logic: "Side Chain" menu at the top of the plugin window.
    Ableton: в заголовке плагина откройте "Sidechain", включите его и
    выберите дорожку-источник в "Audio From".

PRESETS / ПРЕСЕТЫ
  SAVE saves your own preset to Documents/artempidor/Presets.
  Share a .artempidor file: the other person drags it onto the plugin.
  SAVE сохраняет ваш пресет. Чтобы поделиться — перетащите файл
  .artempidor на окно плагина.
